# Demo recording checklist

Before recording
- [ ] Open the deployed app once to warm the serverless function, so the first load is fast.
- [ ] Browser at 100 % zoom, window ≥ 1440 px wide, bookmarks bar and notifications hidden.
- [ ] Tabs ready: deployed app; GitHub repo README; `backend/app/services/forecast_selection.py`;
      `backend/tests/test_forecast_selection.py`; a terminal in the repo; `<app>/docs` (FastAPI docs).
- [ ] Check that the headline numbers on screen match `docs/demo-script.md`. If Elexon has revised data,
      use the on-screen numbers.

Recording (for example OBS, Loom or the Windows Game Bar `Win+Alt+R`)
- [ ] Part 1 ≤ 5:00, customer language, no code.
- [ ] Part 2 ≤ 5:00, code, tests, architecture.
- [ ] Join the parts into one video ≤ 10:00, or upload one video with a title card or a clear spoken switch
      between parts.

Upload
- [ ] YouTube → Create → Upload → Visibility **Unlisted**.
- [ ] Copy the link and open it in an incognito window: it plays without signing in.
- [ ] Paste the link into `docs/submission-checklist.md` and the submission form.
